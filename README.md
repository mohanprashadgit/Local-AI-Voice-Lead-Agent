# Local AI Voice Lead Agent

Autonomous, ultra-low-latency real-time voice agent for **Real Estate Lead Qualification**, operating 100% locally on a single machine. No cloud APIs, no external fees, complete data privacy.

---

## Overview

**Local AI Voice Lead Agent** combines WebRTC bidirectional audio streaming, local speech recognition, streaming LLM inference, and high-speed neural speech synthesis into a conversational real estate assistant.

The assistant interacts via natural voice, captures property preferences, budget, timeline, and buyer readiness in real time, and populates a live qualification card with **HOT / WARM / COLD** lead scoring.

---

## Key Features

- **Real Estate Lead Qualification UI**:
  - Modern dark glassmorphic dashboard with live call timer and status indicators.
  - Right-side lead card displaying **Interest**, **Buyer Type**, **Property Type**, **Budget**, **Location**, **Timeline**, and **HOT / WARM / COLD** qualification badge.
  - Live conversation transcript with separated user and AI dialogue bubbles.
  - Center interactive microphone hub with audio waveform visualizer and hardware mute toggle.
- **Sub-Second Barge-In (Interruption)**: Silero VAD cuts off AI voice playback within ~0.2 seconds (approximately one word) when the candidate speaks.
- **TTS Lookahead Pipelining**: Synthesizes the next speech chunk while the current one is playing through WebRTC, eliminating awkward pauses.
- **Early First-Clause Flushing**: Begins audio synthesis as soon as the first thought clause (~50 characters) is generated by the LLM.
- **100% Offline & Private**: Whisper, Ollama, and Piper all run on your machine without transmitting any audio or customer data to external cloud services.

## Tech Stack

| Layer | Technology | Details |
|---|---|---|
| **Frontend UI** | Next.js 15, React 19, Tailwind CSS | Real-time WebRTC client, dark luxury aesthetic, responsive layout |
| **Transport** | LiveKit Server (`livekit_server/livekit-server.exe`) | Local WebRTC SFU on port `:7880` |
| **STT (Speech-to-Text)** | `faster-whisper` (`base.en` / `large-v3-turbo`) | CTranslate2-accelerated local transcription |
| **VAD** | `silero-vad` (ONNX) | CPU-optimized speech boundary and interruption detector |
| **LLM (Reasoning)** | Ollama (`qwen2.5:0.5b` / `llama3.2:3b`) | Streaming local model inference |
| **TTS (Speech Synthesis)** | Piper ONNX (`en_US-danny-low.onnx`) | High-speed neural voice generation |

## Prerequisites

- **OS**: Windows 10/11 with PowerShell (macOS/Linux compatible with minor path adjustments)
- **Python**: 3.10 or 3.11
- **Node.js**: 18+ and npm
- **Ollama**: [Download Ollama](https://ollama.com) and pull a model:
  ```powershell
  ollama pull qwen2.5:0.5b
  ```

## Setup Instructions

### 1. Python Virtual Environment

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -U pip
.\.venv\Scripts\python -m pip install -r requirements.txt
```

### 2. Frontend Dependencies

```powershell
cd frontend
npm install
cd ..
```

### 3. Models

- **Piper Voice:** Place `en_US-danny-low.onnx` and `en_US-danny-low.onnx.json` into `models/piper/`.
- **Whisper STT:** Whisper `base.en` or `large-v3-turbo` will automatically cache into `models/hub/` on first launch.

### 4. Environment Configuration

Copy the sample environment file:

```powershell
copy .env.example .env.local
```

The default values are pre-configured to match the local LiveKit server.

## Turn Flow Architecture

```
User Microphone
       │
       ▼ (WebRTC Audio Stream)
LiveKit Server (:7880)
       │
       ▼
AgentSession (LiveKit Agent)
 ├─ Silero VAD (CPU) ────────► Barge-in Interruption Detection (0.2s)
 └─ StreamAdapter
     ├─ Silero VAD ──────────► Speech Endpointing
     └─ faster-whisper ──────► Transcript
                                     │
                                     ▼
                          Ollama Streaming LLM
                                     │ (Token Stream)
                                     ▼
                          Sentence/Clause Chunks
                                     │
                                     ▼
                          Piper TTS (Lookahead Pipelined)
                                     │
                                     ▼ (Audio Frames)
                             LiveKit Room Speaker
```

## Configuration Settings (`.env.local`)

| Setting | Purpose |
|---|---|
| `OLLAMA_MODEL` | Local LLM model (e.g., `qwen2.5:0.5b` for fast CPU, `llama3.2:3b` for higher intelligence) |
| `CHAT_NUM_PREDICT` | Maximum token limit per reply to maintain snappy responses |
| `WHISPER_MODEL` | `base.en` for fast CPU transcription, `large-v3-turbo` for highest accuracy |
| `WHISPER_DEVICE` | `cpu` or `cuda` |
| `SILERO_MIN_SILENCE_MS` | Silence duration required to mark end of user speech (default: `350ms`) |
| `BARGE_MIN_SEC` | User speech duration required to interrupt AI voice playback (default: `0.2s`) |
| `PIPER_MODEL` / `PIPER_CONFIG` | Relative path to Piper ONNX model and JSON config |
